# Knowledge Academy

Landing page em coming soon da Knowledge Academy, uma plataforma para professores de inglês organizarem aulas e acompanhar a prática dos alunos com flashcards, áudio nativo e conversação.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Executar localmente

Requisitos: Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Scripts

```bash
npm run dev    # servidor de desenvolvimento
npm run build  # build de produção
npm run start  # servidor de produção
npm run lint   # análise com ESLint
```

## Principais recursos

- Contagem regressiva até a inauguração
- Formatação e validação de WhatsApp
- Estado de confirmação da lista VIP
- Link direto para atendimento pelo WhatsApp
- Layout responsivo e metadados para SEO e redes sociais
